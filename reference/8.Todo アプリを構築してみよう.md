## コマンド集

### 基本リソースの作成

```bash
# デプロイ先リソースグループを指定する
export TF_VAR_resource_group_name="rg-iaas"
```

```bash
# 基本リソースをデプロイする
curl -fsSL https://raw.githubusercontent.com/m-oka-system/microsoft-azure-iaas-part/refs/heads/main/labs/sections/section08/setup.sh | bash
```

### Cloud Shell

```bash
# 秘密鍵が作成されていることを確認する
ls -l ~/.ssh/sshkey-vm.pem

# .env が作成されていることを確認する
ls -l microsoft-azure-iaas-part/src/.env

# .env の中身を確認する
cat microsoft-azure-iaas-part/src/.env

# scp コマンドで VM に .env がコピーできていることを確認する
ls -l .env
```
