## コマンド集

`<LB_PUBLIC_IP>` はロードバランサーの「概要」メニューに表示されるフロントエンド IP アドレスに置き換えます。

### 基本リソースの作成

```bash
# デプロイ先リソースグループを指定する (コース内ラボ環境では不要)
export TF_VAR_resource_group_name="rg-iaas"
```

```bash
# 基本リソースをデプロイする
curl -fsSL https://raw.githubusercontent.com/m-oka-system/microsoft-azure-iaas-part/refs/heads/main/labs/sections/section10/setup.sh | bash
```

### 仮想マシンスケールセット作成後の動作確認

```bash
# ロードバランサー経由でアクセスして Todo アプリの応答が返ってくることを確認する
curl http://<LB_PUBLIC_IP>/health

# SSH 接続できることを確認する
ssh -i ~/.ssh/sshkey-vm.pem azureuser@<LB_PUBLIC_IP> -p 50000

# SSH 接続を切断する
exit
```

### 自動スケールの動作確認

```bash
# VMSS のリソースグループを指定する (コース内ラボ環境の場合は値を修正してください)
export RESOURCE_GROUP="rg-iaas"
```

```bash
# 10 分間 CPU に 負荷をかける
az vmss run-command invoke \
  --resource-group "$RESOURCE_GROUP" \
  --name vmss \
  --instance-id "$(az vmss list-instances --resource-group "$RESOURCE_GROUP" --name vmss --query "[0].instanceId" --output tsv)" \
  --command-id RunShellScript \
  --scripts 'for i in $(seq 1 $(nproc)); do timeout 600 yes > /dev/null & done; wait'
```
