# ハンズオン環境

セクションごとのハンズオン環境を Terraform で構築します。Azure Cloud Shell で実行すると、演習の直前の状態ができます。

受講者は自分の Azure サブスクリプションで実行します。料金は受講者の負担になるため、演習が終わったらリソースグループごと削除します。

受講者は動画の指示に従って実行します。本書はラボのパスと、どのラボでも共通になる事柄を扱います。

## ラボの一覧

| セクション | ラボ                       | 内容                                                 | ラボのパス                |
| ---------- | -------------------------- | ---------------------------------------------------- | ------------------------- |
| 08         | アプリを配置する前の環境   | VM と SQL を作る。アプリは入れない                   | `labs/sections/section08` |
| 09         | ロードバランサの振り分け先 | VM 2 台にアプリを入れる。SQL は作らない              | `labs/sections/section09` |
| 10         | 自動スケールを検証する環境 | VNet・NAT Gateway・SSH 鍵・SQL を作る。VM は作らない | `labs/sections/section10` |

`base` と `section99` は一覧に載せません。デバッグ用で、受講者には案内しないためです。`base` は課金されないネットワーク系だけ、`section99` は完成形を作ります。

## 共通の実行方法

デプロイ先のリソースグループを宣言してから、ラボのパスを埋めて Azure Cloud Shell（Bash）で実行します。パスは上の一覧にあります。

```bash
export TF_VAR_resource_group_name="rg-iaas"
```

```bash
curl -fsSL https://raw.githubusercontent.com/m-oka-system/microsoft-azure-iaas-part/refs/heads/main/<ラボのパス>/setup.sh | bash
```

### リソースグループの指定

`TF_VAR_resource_group_name` の宣言は必須です。未設定のまま実行すると、宣言の例を表示して中止します。唯一のリソースグループを自動で検出することはしません。受講者のサブスクリプションには他のリソースグループが同居し得るためです。

指定したリソースグループが存在しない場合は、`setup.sh` が作成します。場所は東日本（`japaneast`）です。

リソースグループは空である必要があります。前のセクションでポータルから作ったリソースが残っていると、ラボが動画と同じ名前で作ろうとして失敗するため、`terraform apply` の前に中止します。

## 片付け

**環境を残すと課金が続きます。** 確認が終わったら、リソースグループごと削除します。ポータルで作ったロードバランサやスケールセットも同時に消えます。

```bash
az group delete --name rg-iaas --yes
```

仮想マシン・パブリック IP・NAT Gateway には無料枠がありません。データベースの無料枠については[要件定義書の「環境を放置した場合の影響」](../docs/requirements.md#環境を放置した場合の影響)にあります。

Cloud Shell はストレージなしで起動します。セッションが切れれば接続情報と秘密鍵が消えます。マウントすると `$HOME` に残り続けます。

## ディレクトリ構成

```text
labs/
├── README.md              # 本書
├── modules/               # 全ラボで共有する Terraform モジュール
└── sections/
    └── sectionNN/         # コースのセクション番号がそのままラボのルートモジュール
        ├── setup.sh       # Cloud Shell から実行する入口
        └── *.tf           # Terraform
```

1 つのラボを 1 つのディレクトリに閉じます。入口の `setup.sh` と Terraform が同じ場所にあるため、片方だけが移動して対応が切れることがありません。

ディレクトリ名はコースのセクション番号だけにします。動画の番号とラボのパスが 1 対 1 で対応し、セクション名を変えてもパスが変わりません。

state はラボごとに独立しています。他のラボを先に実行しなくても開始できます。

## 設計上の約束

| 約束                                       | 理由                                         |
| ------------------------------------------ | -------------------------------------------- |
| 演習で教える対象は Terraform で作りません  | 受講者がポータルで作る体験がコースの主題     |
| Terraform ではリソースグループを作りません | 片付けをリソースグループの削除に統一する     |
| バックエンドは設定しません                 | 片付けはリソースグループの削除で行うため     |
| プロバイダのバージョンは完全に固定します   | 実行した日によって結果が変わらないようにする |
| リソース名は動画の表示と一致させます       | 受講者が画面と資料を照合できる               |
